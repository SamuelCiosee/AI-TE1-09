# Introduction
Expert System (Sistem Pakar) adalah sistem berbasis komputer yang menggunakan pengetahuan dan aturan dari pakar dalam bidang tertentu untuk menganalisis masalah serta memberikan saran atau rekomendasi. Sistem ini bertujuan membantu pengguna memahami masalah dan mengambil keputusan.  

Expert system yang digunakan merupakan expert system simpel milik Zerfan dengan metode forward chaining, metode tersebut menarik kesimpulan akhir berdasarkan fakta-fakta awal yang disediakan.

Sumber Kode : https://github.com/zerfan/Sistem-Pakar-Diagnosa-Penyakit-Kulit-Forward-Chaining

# Requirement
1. Instal library experta
2. Instal library matplotlib

# How To use
1. Pastikan library experta dan matplotlib terinstal
2. Jalankan sistempakar.py
3. Jawab pertanyaan gejala dengan yes atau no 
4. Hasil diagnosis akan muncul diakhir dengan kemungkinan penyakit, gambar penyakit, deskripsi penyakit, dan saran pengobatan
